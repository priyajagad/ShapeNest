============================================================
MECHANIC CONTRACT (from source — no redesign)
============================================================

Data model
- LevelShutterData: one durability int + list of covered cells
- One ShutterState spawned per LevelShutterData entry
- Visual: one TMP label "ShutterDurability" centered over the AABB of covered cells
- Cell overlays drawn per covered cell; counter is shared

Match → durability
- BlockMover.ConsumeAndRebuild notifies LevelManager.NotifySuccessfulMatch() exactly once
  per successful focused-cell consume (nestCellIndices[0] only)
- NotifySuccessfulMatch iterates ALL spawned shutters and calls ConsumeSuccessfulMatch()
- ConsumeSuccessfulMatch decrements by 1 if still closed; ignores further hits when open

Unlock
- IsClosed <=> durability > 0
- CoversCell returns false when open → entire region unlocks at once
- BoardManager.IsCellBlockedByClosedShutter checks IsClosed, so unlock is immediate at 0
- FeedbackRoutine later UnregisterShutter (presentation cleanup)

Structure coverage
- Gates are cell/footprint based (GetLocalCell), not structure-type specific
- Single / chain / Shape-in-Shape / nested chain all share the same shutter lock path
- Drag begin rejects IsBlockUnderClosedShutter
- Auto-match scan skips shuttered candidates
- CanTranslateBlock rejects footprints that touch closed shutters

Independent shutters
- Separate ShutterState instances + separate counters/labels
- They share the GLOBAL successful-match bus (every match decrements every closed shutter)
- Level8 (6× durability-1 shutters) therefore all open on the first successful match anywhere
